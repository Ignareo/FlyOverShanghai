# 外部模型导入位

把下载好的 GLB 模型放到本目录，网页会自动加载；文件不存在时自动回退到内置程序化模型，无需改代码。

## 武直十（主角）

文件名必须是：**`z10.glb`**

- 推荐来源：Sketchfab「Changhe Z-10」（CC 协议，低模适合网页）
- 代码会自动：居中、缩放至约 14 米机长、机头对齐
- 若模型内节点名含 rotor / prop / blade（或 tail），主旋翼和尾旋翼会被自动识别并转动；识别不到则自动挂载内置旋翼组件，动效一定有
- 若加载后机头方向不对，改 `src/three/glb.ts` 顶部的 `YAW_FIX`（如 `Math.PI` 转 180°）

## 可选：整个上海城市（陆家嘴+外滩）

文件名必须是：**`shanghai.glb`**

- 推荐来源：Sketchfab「City- Shanghai-Sandboxie」（CC 署名协议），下载时选 glTF/GLB 格式
- 加载成功后会**整体替换**程序化陆家嘴地标和外滩建筑群，黄浦江 / 江岸灯带 / 外围街区 / 南浦大桥保留
- 黄浦江中心线在核心城区段会**贴合该模型的河道**（模型 scale=800、offset=(420,0) 下实测的控制点，见 `src/three/city.ts` 的 `MODEL_RIVER`）；如果调整了 `SHANGHAI_GLB_TUNE` 的缩放 / 旋转 / 平移，这些控制点也需要同步更新
- 模型本身带地理坐标，代码不强制改尺寸，只做对齐。如果对不齐（偏移 / 旋转 / 大小不对），调 `src/three/glb.ts` 里的 `SHANGHAI_GLB_TUNE`：
  - `scale`：缩放倍数（模型单位可能不是米，常见需要 1~1000 倍之间调整）
  - `rotY`：旋转（弧度，`Math.PI` = 180°）
  - `offsetX / offsetZ`：平移（默认把模型中心对齐到程序化核心区 (420, 0)）
  - `autoGround`：自动贴地 + 居中，关掉则完全手动控制位置
- 41 万面的模型加载需要几秒，属正常

## 可选：单个地标替换（放进来就替换对应的程序化地标）

| 文件名 | 替换对象 | 放置位置 |
|---|---|---|
| `pearl.glb` | 东方明珠 | (460, 0, -60) |
| `shanghai-tower.glb` | 上海中心大厦 | (350, 0, 190) |
| `swfc.glb` | 环球金融中心 | (300, 0, -280) |
| `jinmao.glb` | 金茂大厦 | (530, 0, 100) |

会自动按目标高度等比缩放（东方明珠 470m、上海中心 632m 等）。

## 音效

`public/audio/rotor.mp3` 已内置旋翼音效，按任意键起飞后自动播放，音量音调随油门变化，按 **M** 静音。想换成自己的音效，直接覆盖该文件即可。
